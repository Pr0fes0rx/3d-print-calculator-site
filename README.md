# 3D Print Calculator website

GitHub Pages: Settings > Pages > Deploy from branch main / root.
Edit text in _build/build.py then run: python _build/build.py
English: index.html | Arabic: ar/index.html

Countries panel data: COUNTRIES list in _build/build.py (sample values, edit there).

Filament spools: img/spool-{rainbow,gloss,glow,pink}.webp (1 kg spool render). Wired in _build/build.py (_spool), angles/effects in site.css (.spool.s1-s4).
